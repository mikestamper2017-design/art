# Summer Art Show AR Tool Assets Checklist

To ensure your code tracks successfully, make sure your media assets match these exact filenames when you upload them directly to this repository folder:

### 1. Target Tracking Configuration Brain
* `targets.mind` : The compiled file exported from MindAR's compiler containing both your painting photograph and your sculpture's companion photo card.

### 2. Painting Assets
* `painting-video.mp4` : The video loop overlay that plays directly on top of your physical watercolor painting canvas.

### 3. Sculpture Process Stage Photographs
* `phase-raw.jpg` : Photograph tracking the raw, uncarved soapstone material block.
* `phase-chisel.jpg` : Photograph documenting the mid-production structural chisel pass.
* `phase-finished.jpg` : Photograph presenting the polished, finished display sculpture.

### 4. Audio Components
* `audio-commentary.mp3` : Your vocal studio commentary file breaking down materials, methods, or your creative narrative.
